# 🐰🔥 토끼 병사단의 야영지 · 모바일 (Camfire Game Mobile)

> [토끼 병사단의 야영지](https://www.google.com/search?q=https://github.com/jeongseoyun0320-dev/camfiregame)를 휴대폰 터치로 플레이할 수 있게 만든 **모바일 버전**입니다.

60초 안에 멧돼지를 사냥해 굽고, 쓰러진 동료를 살릴 약초를 캐 약을 만드는 8비트 세피아 톤 타임어택 어드벤처.
설치 없이 브라우저에서 바로 플레이할 수 있는 HTML 파일 하나짜리 게임입니다.

## 📱 터치 조작법

| 조작 | 동작 |
| --- | --- |
| 왼쪽 아래 조이스틱 | 이동 (아무 곳이나 터치하면 그 자리에 생김, 8방향) |
| 🔴 작살 버튼 | 작살 던지기 (조이스틱 방향으로) · 2부에선 **괭이**로 약초 캐기 |
| 🟢 E 버튼 | 굽기·꺼내기 / 도구 교체 / 절구에 넣기·꺼내기 / 약병 주기 (누를 수 있을 때 노랗게 빛남) |
| ↻ | 다시 시작 |
| ⛶ | 전체 화면 (지원하는 브라우저에서만 표시) |
| 안내 화면 터치 | 시작 / 다시 하기 |

* **가로 화면**: 게임이 꽉 차고 버튼이 반투명하게 겹쳐 표시됩니다 (추천)
* **세로 화면**: 위에 게임, 아래에 조작 버튼
* **Safari 브라우저**: 아이폰 Safari에서 열면 주소표시줄을 숨기고 더욱 쾌적한 화면으로 플레이할 수 있습니다.
* 키보드(방향키/WASD, Space, E, R, Enter)도 그대로 사용할 수 있습니다.

## 🎮 게임 방법

1. **PART 1 — 멧돼지 타임어택**: 60초 안에 멧돼지 15마리를 작살로 잡아 모닥불에 굽기 (3초면 익고, 12초 넘으면 탐)
2. **잔치 & 이야기**: 다 같이 고기를 먹고 나면 갈색 토끼가 쓰러짐
3. **PART 2 — 약초 타임어택**: 오른쪽 숲 도구 걸이에서 괭이로 바꾸고, 60초 안에 약초 25개를 캐 절구로 약 만들기 (빨간 독버섯 주의)
4. **엔딩**: 약병을 쓰러진 토끼에게 전해주기 💊 → ♥

## 🛠 기술 스택

* HTML5 Canvas + 순수 JavaScript (라이브러리 없음, 이미지 파일 0개)
* 192×108 저해상도 캔버스를 화면 크기에 맞게 확대
* Pointer Events 기반 멀티터치 가상 조이스틱/버튼
